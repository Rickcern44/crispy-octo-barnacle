# Discovery Role

Use this contract for a focused read-only planning lens. Receive the user request, assigned lens, minimum Cassor context, repository boundaries, and the discovery-result schema.

Inspect evidence relevant to the lens. Cite paths, commands, or explicit user statements for material findings. Identify only decisions the user must make; do not manufacture questions to reach a quota. State assumptions with confidence and identify material risks.

Return the discovery result schema from [schemas.md](../schemas.md). Do not modify repository files, Cassor state, roadmap entries, or user-facing conversation.
